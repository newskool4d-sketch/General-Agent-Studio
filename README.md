# General Agent Studio

요청과 참고자료로 문서 초안을 만들고, 내용을 확인해 HWPX로 저장하는 Windows 앱입니다.

[최신 설치 파일과 릴리스 노트](https://github.com/newskool4d-sketch/General-Agent-Studio/releases/latest)

이 저장소는 **General Agent Studio의 설치 파일·업데이트 파일·사용 안내서 배포용**입니다.

## 설치

릴리스에서 `General-Agent-Studio-Setup-0.6.0.exe`를 받아 설치합니다. 설치 후 앱 상단의 제품명과 버전을 확인하세요. 파일의 SHA-256과 서명 상태는 해당 릴리스 노트에서 확인할 수 있습니다.

General Agent Studio는 기존 **ICE Agent Studio와 별도로 설치**됩니다. 기존 앱과 이전 버전 설치 파일을 대체하지 않습니다. 두 앱의 기관 설정·전송 동의·업데이트 경로도 분리됩니다. 이전 문서는 `.iceplan` 작업 파일로, 기관 정보는 `.iceprofile` 파일로 저장한 뒤 새 앱에서 불러오세요.

## 세 가지 시작 방식

- **새 문서 만들기:** 요청을 적고 참고자료를 추가해 초안을 만듭니다. 새 계획안 작성·기존 사업 개선·공문 분석·회신·아이디어 정리 중 작업을 고릅니다.
- **기존 문서 다듬기:** HWP·HWPX·TXT·MD 문서를 가져옵니다.
- **하던 작업 이어하기:** 저장한 `.iceplan`을 엽니다.

진행 순서는 **내용 준비 → 문서 꾸미기 → 확인하고 저장**입니다. 상단 **우리 기관**에서 기관명·부서·PNG/JPG 로고를 직접 입력하고, **다음 문서에도 이 기관 정보 사용**을 선택하면 이 기기에 저장합니다. 로고 없이 사용할 수도 있습니다.

## 참고자료

HWP·HWPX·PDF·DOCX·XLSX·CSV·TXT·MD를 참고자료로 추가할 수 있습니다. 최대 8개, 파일당 30MB이며 실행 전에 파일별 읽기 결과와 사용할 분량을 표시합니다.

PDF는 쪽, DOCX는 구역, XLSX는 시트·셀 범위로 출처를 표시합니다. DOCX 구역은 실제 인쇄 쪽 번호와 다릅니다. 사용할 범위를 바꾸면 이전 확인은 해제됩니다. 숨김 시트는 기본 선택에서 제외하고, 수식은 저장된 계산값만 읽습니다. 스캔 PDF 등 읽지 못한 내용은 안내를 확인해 별도 텍스트로 보완하세요.

> **음성 회의록 안내**  
> 음성 회의록은 먼저 텍스트로 전사한 뒤 TXT 또는 MD 파일로 첨부해 주세요.

PDF·DOCX·XLSX·CSV는 내용을 읽어 작성에 참고하는 기능입니다. 해당 파일 자체를 편집하는 기능은 제공하지 않습니다.

## 준비할 것

- AI 기능: 공식 Claude Code 또는 Codex CLI와 앱이 지원하는 웹 구독 계정 로그인
- HWPX 생성: Python 3.11 이상
- 출력 확인: HWPX 호환 편집기 및 서식에서 사용하는 글꼴(HY헤드라인M·휴먼명조·맑은 고딕)

상단 **AI 연결**에서 서비스 상태를 확인합니다. Codex는 General Agent Studio 전용 환경에 새로 로그인하며, 기존 ICE Agent Studio의 Codex 인증을 자동으로 복사하지 않습니다. 비밀번호나 토큰을 앱의 요청 입력란에 넣지 마세요. 인증은 공식 CLI의 로그인 과정에서 처리합니다.

외부 AI 전송 동의는 기본 꺼짐입니다. 실행 시 요청·문서 본문·선택한 참고자료 내용이 선택한 서비스로 전송됩니다. **법령 확인 후 작성**을 켜면 초안 서비스와 별도로 Claude에도 일부 자료가 전송될 수 있으므로 화면의 전송 안내를 확인하세요.

## 저장과 확인

이어서 수정할 때는 **파일 → 작업 저장**으로 `.iceplan`을 남깁니다. 최종 문서는 **한글 파일 저장 (.hwpx)**으로 저장하고 편집기에서 쪽 나눔·표·글꼴·수치를 확인하세요. 작업 저장과 HWPX 저장은 각각 수행합니다. AI 초안의 `[확인 필요]`·`[추정]` 표시와 근거는 담당자가 확인해야 합니다.

자세한 단계와 문제 해결은 릴리스에 첨부된 **General-Agent-Studio-Guide.html**에서 볼 수 있습니다. 안내서는 내려받아 오프라인으로 읽을 수 있습니다.
