설치와 준비

  1. 배포 페이지에서 General-Agent-Studio-Setup-0.6.0.exe를 받습니다. 파일의 SHA-256과 서명 상태는 같은 릴리스 노트에서 확인하세요.
  2. 설치 안내에서 위치를 확인하고 설치합니다. 설치 후 General Agent Studio를 엽니다.
  3. 상단의 제품명과 버전을 확인하고, 기존 문서는 .iceplan 또는 지원하는 문서 파일로 가져옵니다.
기존 ICE Agent Studio와 별도로 설치합니다.기존 앱과 이전 버전 설치 파일을 대체하지 않습니다. 기관 설정·전송 동의·업데이트 경로도 분리됩니다. 기존 앱의 설정이 자동으로 옮겨진다고 가정하지 말고, 작업 파일과 기관 설정 파일을 새 앱에서 직접 불러오세요.

사용 전에 준비할 것

  • AI 기능: 공식 Claude Code 또는 Codex CLI와 앱이 지원하는 웹 구독 계정 로그인
  • HWPX 생성: Python 3.11 이상. 앱은 Windows에서 py 런처를 먼저 시도하고 python으로도 실행을 시도합니다.
  • 최종 확인: HWPX 호환 편집기와 서식 글꼴. 기본 서식은 HY헤드라인M·휴먼명조·맑은 고딕을 사용하며 글꼴이 없으면 출력 모양이 달라질 수 있습니다.

앱은 Python·공식 AI CLI·글꼴을 자동으로 설치하지 않습니다. 조직 PC에서 설치가 제한되면 전산 담당자에게 확인하세요.

먼저 시작 방법을 고르세요

새 문서 만들기

만들고 싶은 내용을 적고 참고자료가 있으면 추가합니다. 새 계획안 작성·기존 사업 개선·공문 분석·회신·아이디어 정리 중 작업을 고릅니다.

기존 문서 다듬기

HWP·HWPX·TXT·MD를 가져옵니다. 내용과 서식을 확인하며 편집합니다.

하던 작업 이어하기

저장해 둔 .iceplan을 엽니다. 이전 문서와 확인 상태를 이어서 검토합니다.

새 문서의 요청에는 목적·대상·기간·알고 있는 예산·꼭 넣을 내용을 적으세요. 아직 모르는 값은 모른다고 적고 생성 뒤 확인합니다.

내용 준비 → 문서 꾸미기 → 확인하고 저장

내용 준비

문서를 만들거나 가져온 뒤 내용을 확인합니다. 문서 종류, 목차·요약 구성, 확인할 수치와 추정 표시를 검토합니다.

문서 꾸미기

제목·기관을 입력하고 쪽 구성·서식을 확인합니다. 각 쪽의 역할과 항목기호를 살펴본 뒤 확정합니다.

확인하고 저장

수정 제안을 적용하거나 원문을 유지합니다. 남은 항목을 확인한 다음 HWPX로 저장합니다.

다음 버튼 옆 안내를 확인하세요.세 묶음 안에는 기존의 내용·목차, 제목·기관, 쪽별 구성, 수정 제안 확인 절차가 유지됩니다. 진행이 막히면 현재 화면의 미확인 항목과 다음 행동 안내를 먼저 보세요.

가져온 HWPX는 실조판으로 실제 쪽을 탐색합니다. 빠른 미리보기의 논리 쪽 번호와 실제 쪽 번호가 같다고 가정하지 마세요.

상단 ‘우리 기관’에서 직접 입력합니다

  1. 기관명과 필요한 부서명을 입력합니다. 기관명은 필수입니다.
  2. 로고가 있으면 PNG·JPG 파일을 넣습니다. 최대 2MB입니다. 로고를 쓰지 않으면 로고 없이 사용을 고릅니다.
  3. 입력 아래의 기관 정보 미리보기를 확인합니다. 추가 정보·표지 서식에서 영문명·슬로건·표지 모양을 정할 수 있습니다.
  4. 다음 문서에도 이 기관 정보 사용을 체크하면 현재 정보를 이 기기에 저장합니다.

표지 서식을 바꿔도 기관명과 로고는 유지됩니다. 저장한 정보와 다르게 수정했으면 재사용 선택 상태를 다시 확인하세요.

다른 기기나 기존 앱에서 가져올 때기관 설정 파일로 보관·불러오기에서 .iceprofile을 저장하거나 엽니다. 작업 저장본에도 기관명·부서·로고를 보관합니다. 불러온 저장본의 기관 정보가 이 기기의 기본 기관 정보보다 우선합니다.

참고파일은 읽기 결과부터 확인하세요

참고자료 추가에서 직접 고른 파일을 읽습니다. 최대 8개, 파일당 최대 30MB입니다. 실행 전 파일별 읽기 결과·사용할 분량·읽기 안내를 확인하세요. 파일이 크거나 읽지 못한 내용이 있으면 일부만 사용할 수 있으며, 필요한 확인을 마쳐야 진행됩니다.

음성 회의록 안내음성 회의록은 먼저 텍스트로 전사한 뒤 TXT 또는 MD 파일로 첨부해 주세요.
형식출처·사용 범위확인할 내용
PDF실제 쪽 번호로 표시하고 사용할 쪽을 고릅니다.스캔 쪽·그림 속 내용 등 읽지 못한 부분은 텍스트로 보완합니다. 복잡한 표의 배치는 원문과 대조합니다.
DOCX구역을 기준으로 표시합니다.구역은 실제 인쇄 쪽 번호와 다릅니다. 본문·표·각주와 읽기 누락 안내를 확인합니다.
XLSX시트와 셀 범위를 표시하고 사용할 시트를 고릅니다.숨김 시트는 기본 선택에서 제외합니다. 수식은 저장된 계산값을 읽으며 재계산하지 않습니다. 계산값이 없으면 해당 안내를 확인합니다.
CSV표의 행·열을 기준으로 읽습니다.제목·단위·선행 0과 숫자가 의도대로 읽혔는지 확인합니다.
HWP·HWPX·TXT·MD추출한 본문을 참고자료로 읽습니다.내용과 사용할 분량을 확인합니다. 회의록 전사본은 TXT·MD로 넣습니다.

PDF·DOCX·XLSX·CSV는 내용을 참고하는 용도입니다. 해당 파일 자체를 편집하는 기능은 제공하지 않습니다. 사용할 쪽·구역·시트를 바꾸면 이전 읽기 확인이 해제되므로 다시 확인하세요. 음성 파일 직접 전사와 OCR은 지원하지 않습니다.

AI 연결과 외부 전송 동의를 확인하세요

  1. 상단 AI 연결을 열고 사용할 서비스의 로그인 상태를 확인합니다.
  2. 로그인이 필요하면 앱의 로그인 버튼으로 공식 인증 과정을 진행합니다. 비밀번호·토큰은 문서 요청이나 자료에 붙여 넣지 않습니다.
  3. 인증 후 상태 새로고침으로 ‘연결됨’을 확인합니다.
  4. 전송 범위를 읽고 외부 AI 전송 동의를 직접 켭니다. 기본 상태는 꺼짐입니다.

Claude는 이 PC의 공식 Claude Code 로그인 상태를 사용합니다. Codex는 General Agent Studio 전용 환경에 별도 로그인하며, 기존 ICE Agent Studio의 Codex 인증을 자동으로 가져오지 않습니다. 앱은 인증 토큰 파일을 직접 읽고 관리하지 않고 공식 CLI에 인증을 맡깁니다. API 키·종량 과금 로그인 경로는 허용하지 않습니다.

실행할 때 요청과 자료 내용이 외부 AI로 전송됩니다.요청·문서 본문·선택한 참고자료 내용이 선택한 서비스로 전송됩니다. 법령 확인 후 작성을 켜면 초안을 Codex로 작성하더라도 제목·요청과 참고자료 앞부분 최대 12,000자가 Claude(Anthropic)에도 전송될 수 있습니다. 화면에 표시된 서비스와 전송 안내를 확인하고, 전송할 권한이 없는 자료는 첨부하지 마세요.

앱에 포함된 에이전트·스킬 기준은 배포본의 사본입니다. 개인 PC의 스킬 변경이 자동으로 반영되거나 모든 외부 도구가 실행된다고 가정하지 마세요.

새 버전 확인

설치된 General Agent Studio는 새 배포 주소에서 업데이트를 확인합니다. 새 버전이 준비되면 작업을 저장한 뒤 다시 시작해 적용을 선택합니다. 앱을 그냥 종료했다고 자동 설치하지는 않습니다. 기존 ICE Agent Studio는 별도 배포 경로를 유지합니다.

진행이 막힐 때

초안 만들기 버튼을 누를 수 없습니다.

AI 서비스가 연결됐는지, 외부 전송 동의가 켜졌는지 확인하세요. 참고파일 읽기가 끝났는지, 일부 사용·읽기 안내 확인이 필요한지도 보세요. 기존 사업 개선·공문 분석·회신은 자료가 필요합니다.

다른 앱에서 Codex에 로그인했는데 연결되지 않습니다.

General Agent Studio는 전용 Codex 환경을 사용합니다. 이 앱의 AI 연결에서 로그인한 뒤 상태를 새로고침하세요. 공식 CLI 설치·계정 권한·사용량 제한도 확인합니다.

파일을 읽지 못하거나 일부 내용이 빠졌습니다.

파일별 안내를 읽고 사용할 범위를 다시 고르세요. 암호·손상·내용 없는 파일은 원본 상태를 확인합니다. 스캔 PDF·그림 속 내용은 필요한 부분을 TXT·MD로 준비해 추가하세요. 범위를 바꾸면 읽기 확인을 다시 해야 합니다.

다음 단계나 저장 단계가 잠겨 있습니다.

현재 화면의 다음 행동 안내를 확인하세요. 문서 종류·목차·요약, 제목·기관, 쪽별 구성, 남은 수정 제안을 차례로 확인해야 합니다. 기관명이 비어 있거나 로고를 읽는 중에도 진행이 제한됩니다.

Python이나 글꼴을 찾을 수 없다고 나옵니다.

Python 3.11 이상과 필요한 글꼴이 준비돼 있는지 확인하고 앱을 다시 여세요. 글꼴이 대체되면 줄바꿈과 쪽 수가 달라질 수 있습니다. 출력 문서를 편집기에서 확인하세요.

기존 앱의 기관 정보가 새 앱에 보이지 않습니다.

두 앱의 설정 저장소는 분리돼 있습니다. 기존 앱에서 저장한 .iceprofile을 불러오거나, 기관 정보가 포함된 .iceplan 작업 파일을 엽니다. 새 앱에서도 다음 문서에 쓰려면 재사용 선택을 확인하세요.
